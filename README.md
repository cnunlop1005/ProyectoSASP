# Descripción de la plataforma
La plataforma que hemos creado se llama ReCode y consistiría en una página donde puedes seleccionar que dispositivos te hacen falta 
y esta te pondrá en contacto con quién ya no necesite ese dispositivo, todo esto para que le puedas dar una segunda vida y no sea desechado cuando sigue siendo funcional.
También podrás seleccionar código y podrás utilizar el código que otra persona ya no utilice.
En la página web se habla más sobre ReCode y sobre su relación con la sostenibilidad.
