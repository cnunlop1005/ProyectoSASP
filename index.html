Tecnología que se reutiliza, impacto que se reduce

ReCode es una plataforma que permite a empresas, centros educativos y organizaciones compartir y reutilizar tanto código como dispositivos tecnológicos, reduciendo así los residuos y favoreciendo a la sostenibilidad y la economía circular. Esto se logra permitiendo que empresas, centros educativos y organizaciones pongan en la plataforma dispositivos o código que ya no vayan a utilizar, para que otros puedan darles uso y evitar así que sean desechados cuando aún pueden seguir siendo útlies.

El problema actual

Cada año se generan millones de toneladas de residuos electrónicos. Muchos dispositivos funcionales se desechan prematuramente, aumentando el consumo de recursos y la contaminación ambiental. También una gran cantidad de código se deja de utilizar y otras empresas podrían llegar a utilizarlo.

Nuestra solución

  • Reutilización de dispositivos tecnológicos
  • Reducción de residuos electrónicos
  • Acceso a tecnología para colectivos con menos recursos
  • Promoción de un consumo responsable
